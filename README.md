# Matemáticas II · Guía para aprobar

Guía de estudio de **Matemáticas II** (Grado en Ingeniería Electrónica y Automática, UPCT).

5 temas con **7 figuras interactivas**: sumas de Riemann frente al valor exacto, límites en varias variables por caminos (iterados, rectas, curvas y polares), curvas de nivel con gradiente y derivada direccional, integral doble con cambio de orden y polares, campo de direcciones de una EDO con sus soluciones, volúmenes de revolución (discos y capas) y clasificación de extremos con el hessiano.

Incluye 21 cuestiones de teoría respondidas, 10 problemas resueltos paso a paso (el primer parcial de abril de 2021 completo), las hojas de ejercicios con estrategia y el formulario.

Datos del curso 2021/22. Página creada en noviembre de 2026.
